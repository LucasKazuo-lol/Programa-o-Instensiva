# Estudos de Programação em Java

Exercícios introdutórios de Java para praticar variáveis, saída no terminal, leitura de dados e cálculos.

## Conteúdo

| Arquivo | Objetivo |
| --- | --- |
| [Prog02.java](InstensivoPrograma%C3%A7%C3%A3oK_/Prog02.java) | Ler nome e três notas com `Scanner` e calcular a média. |
| [Prog01.java](InstensivoPrograma%C3%A7%C3%A3oK_/Prog10/Prog01.java) | Declarar variáveis `String`, `int` e `double` e imprimir seus valores. |

## Requisitos

Um JDK instalado, com os comandos `java` e `javac` disponíveis no terminal.

```bash
java -version
javac -version
```

## Como executar

Clone o repositório e entre na pasta dos exercícios:

```bash
git clone https://github.com/LucasKazuo-lol/Programa-o-Instensiva.git
cd Programa-o-Instensiva
cd "InstensivoProgramaçãoK_"
```

Para o exemplo de média:

```bash
javac -encoding UTF-8 Prog02.java
java Prog02
```

Digite o nome e as três notas inteiras quando solicitado.

Para o exemplo de variáveis, a partir da mesma pasta:

```bash
javac -encoding UTF-8 Prog10/Prog01.java
java Prog10.Prog01
```

O segundo exemplo declara o pacote `Prog10`; por isso, ele deve ser executado com o nome `Prog10.Prog01`, a partir da pasta que contém `Prog10`.

## Sobre o repositório

Os programas são exemplos didáticos independentes, sem dependências externas. Os arquivos `.class` são gerados pela compilação local.
